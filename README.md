# Meme Wiki

## 실시간 LLM 검색

상황 검색은 `/api/recommend`를 호출합니다. OpenAI 임베딩으로 문장의 의미에 가까운
밈 후보 32개를 찾고, LLM이 상황과 대화 상대를 해석하여 추천 순서와 이유를 작성합니다.
추천은 기존 위키 문서의 ID로 검증되며 AI가 없는 문서를 새로 만들지 못하도록 제한합니다.
문서 임베딩은 SQLite에 저장하여 다음 검색에서 재사용합니다. 새 업로드와 수정된 문서는
다음 검색 때 자동으로 임베딩됩니다. 첫 검색은 전체 문서 임베딩 때문에 시간이 더 걸립니다.

서버에 `OPENAI_API_KEY`를 설정해야 실제 검색을 사용할 수 있습니다.
`OPENAI_SEARCH_MODEL`과 `OPENAI_EMBEDDING_MODEL`로 모델을 변경할 수 있습니다.
AI 서버나 키가 없으면 연결 실패를 표시하며 키워드 검색을 AI 결과로 표시하지 않습니다.
검색어와 검색 후보의 위키 문서는 OpenAI에 전송됩니다. 임베딩과 LLM 호출에 API 비용이 발생합니다.

GitHub Pages 빌드는 저장소의 Actions 변수 `MEMEWIKI_API_BASE`를 읽습니다.
여기에 배포된 HTTPS API 서버 주소를 설정한 뒤 빌드하면 기존 사이트에서 LLM 검색과
이미지 등록을 이용할 수 있습니다. API 키는 Actions 변수나 공개 정적 파일에 넣지 말고
API 서버의 비밀 설정에 저장하세요. 서버 배포와 실제 키 연결은 아직 완료되지 않았습니다.

서버 배포용 `Dockerfile`을 제공합니다. 컨테이너 실행 시 `OPENAI_API_KEY`를 비밀 환경
변수로 지정하고 `/data`에 영구 디스크를 연결하세요. 기본 포트는 8080이며 호스팅의
`PORT` 환경 변수를 지원합니다. 이 폴더의 `.env`는 컨테이너 이미지에 포함되지 않습니다.

## 이미지 업로드 및 AI 자동 등록

`feature/ai-meme-upload` 브랜치는 이미지 등록 버튼, OpenAI 이미지 분석,
사용자 업로드 저장 기능을 추가합니다. AI가 생성한 문서는 사용자가 확인한 후 저장하며,
감정·상황·수신인 분류, 설명, 활용 예시와 키워드를 기존 위키에서 검색할 수 있습니다.
JPG, PNG, WebP 이미지를 한 번에 최대 5장, 장당 10MB까지 등록할 수 있습니다.

### 로컬 실행 (PowerShell)

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
# .env의 OPENAI_API_KEY에 본인의 키를 설정하세요.
.\.venv\Scripts\python.exe -m uvicorn web.server:create_app --factory --host 127.0.0.1 --port 8000
```

브라우저에서 http://127.0.0.1:8000 을 엽니다. 이미지 등록 창에서 파일을 선택하거나
끌어놓고 `선택 이미지 분석`을 누릅니다. 이미지별로 AI 분석 결과를 확인하고 제목,
상황 설명, 활용 예시, 감정·상황·수신인·수위 분류, 키워드와 주의사항을 수정할 수 있습니다.
이미지의 제외 버튼으로 저장할 항목에서 제거할 수 있으며 실패한 이미지만 다시 분석할 수 있습니다.
`확인한 내용 저장`을 눌러야 남은 이미지와 수정한 내용이 위키에 함께 저장됩니다.
분석 단계에서는 위키에 등록하지 않으며 임시 이미지는 24시간 후 만료됩니다.
창을 닫아도 현재 페이지에서는 편집 내용이 유지되지만 페이지를 새로고침하면 초안은 사라집니다.
`모두 취소`하면 선택한 이미지를 모두 제외합니다. 이미 등록된 이미지도 다시 올려 내용을
수정할 수 있습니다. 최종 저장하면 기존 문서가 수정되며 이미지와 문서 ID, 최초 등록일은 유지됩니다.
이미지와 분석 결과는 `.state/uploads.sqlite3`에 함께 저장되어 서버 재시작 후에도
유지됩니다. 동일한 이미지는 재등록하거나 다시 분석하지 않습니다.
AI 분석 실패 시 위키에 문서와 이미지를 저장하지 않으며 다시 시도할 수 있습니다.
이미지 등록 동의 문구에는 OpenAI 전송 및 위키 공개가 안내됩니다.

`OPENAI_MODEL`로 분석 모델을 변경할 수 있습니다. 기본값은 `gpt-4o-mini`입니다.
키를 설정하지 않아도 기존 위키는 사용할 수 있지만 새 이미지 분석은 비활성화됩니다.
키는 서버 환경 변수 또는 Git에서 제외된 `.env`에만 저장하세요.
API 연결 방식: [OpenAI 이미지 분석](https://developers.openai.com/api/docs/guides/images-vision),
[구조화된 출력](https://developers.openai.com/api/docs/guides/structured-outputs).

### GitHub Pages에서 연결

GitHub Pages 자체는 AI 호출이나 파일 저장 서버를 실행할 수 없습니다.
위 Python 서버를 HTTPS로 별도 배포하고 영구 디스크를 연결해야 합니다.
`MEMEWIKI_STORAGE_DIR`를 영구 디스크 경로로 설정하고 해당 SQLite 파일을 백업하세요.
배포된 서버에 `OPENAI_API_KEY`와 `MEMEWIKI_ALLOWED_ORIGINS=https://sieunkim99.github.io`
를 설정합니다. 공개 업로드 서버를 운영할 때는 호스팅의 요청 제한과 API 비용 한도를
설정하세요. 이 구현은 계정 인증 없이 방문자가 등록하는 방식입니다.

정적 사이트를 빌드할 때 아래 환경 변수를 전달하면 기존 데이터 대신 서버의 최신
위키 데이터를 읽고 이미지 등록 요청을 해당 서버에 보냅니다.

```powershell
$env:MEMEWIKI_API_BASE = "https://your-api.example.com"
python web/build_static.py
```

GitHub Actions로 빌드한다면 같은 변수를 빌드 단계의 `env`에 설정하세요.
변수 없이 빌드한 정적 사이트는 기존처럼 조회할 수 있고 등록 서버 미연결 상태를
표시합니다. 사용자 업로드는 운영 서버의 SQLite에 저장되며 Git 원본 데이터나
정적 빌드에 자동으로 커밋되지는 않습니다.

## 주요 기능

- **밈 탐색**: 이미지 카드를 둘러보고 각 밈의 상세 설명을 확인합니다.
- **상황 추천**: “월요일 출근하기 싫을 때”, “시험 망쳤는데 후회는 없을 때”처럼 상황을 입력하면 관련 밈과 추천 이유를 보여줍니다.
- **카테고리 필터**: 감정, 상황, 수신인, 수위, 데이터 출처를 조합해 원하는 밈을 찾습니다.
- **밈 상세 정보**: 상황 설명, 실생활 활용 예시, 감정과 표현 의도, 유머 유형, 키워드, 주의사항과 연관 밈을 확인합니다.
- **이미지 활용**: 밈 이미지를 내려받거나 이미지 주소를 복사할 수 있습니다.
- **랜덤 밈과 통계**: 무작위로 밈을 발견하고 감정·상황별 데이터 분포를 살펴봅니다.

## 추천 방식

이 브랜치의 상황 추천은 임베딩 검색과 LLM 추천을 사용합니다. 기존 공개 사이트는
아직 이전의 키워드 검색 버전이며, 이 브랜치와 API 서버를 배포해야 실시간 LLM 검색으로 전환됩니다.
추천 이유는 LLM이 작성하며 일치 확률을 의미하는 퍼센트는 표시하지 않습니다.
밈의 해석과 적절한 사용 맥락은 대화 상대와 상황에 따라 달라질 수 있으므로,
상세 설명과 주의사항을 함께 확인해 주세요.
