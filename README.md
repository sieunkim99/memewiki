# Meme Wiki

**상황과 감정에 어울리는 한국어 밈을 찾는 위키입니다.**

대화 중 어떤 짤을 보내야 할지 고민될 때, 지금의 기분이나 상황을 입력하고 어울리는 밈을 찾아볼 수 있습니다. 이미지와 함께 의미, 활용 예시, 표현 의도, 추천 수신인, 사용 시 주의사항을 제공해 맥락에 맞는 밈을 고르는 데 도움을 줍니다.

[**Meme Wiki 바로가기 →**](https://sieunkim99.github.io/memewiki/)

## 주요 기능

- **밈 탐색**: 이미지 카드를 둘러보고 각 밈의 상세 설명을 확인합니다.
- **상황 추천**: “월요일 출근하기 싫을 때”, “시험 망쳤는데 후회는 없을 때”처럼 상황을 입력하면 관련 밈과 추천 이유를 보여줍니다.
- **카테고리 필터**: 감정, 상황, 수신인, 수위, 데이터 출처를 조합해 원하는 밈을 찾습니다.
- **밈 상세 정보**: 상황 설명, 실생활 활용 예시, 감정과 표현 의도, 유머 유형, 키워드, 주의사항과 연관 밈을 확인합니다.
- **이미지 활용**: 밈 이미지를 내려받거나 이미지 주소를 복사할 수 있습니다.
- **랜덤 밈과 통계**: 무작위로 밈을 발견하고 감정·상황별 데이터 분포를 살펴봅니다.

## 추천 방식

상황 추천은 입력한 문장을 밈의 키워드, 상황 설명, 활용 예시, 감정·상황 분류와 비교해 관련 항목을 보여주는 방식입니다. 현재 공개 사이트는 브라우저 안에서 저장된 데이터를 검색하며, 이용자의 입력을 외부 LLM API로 전송하지 않습니다.

화면에 표시되는 일치율은 검색 점수를 바탕으로 계산한 참고 값입니다. 밈의 해석과 적절한 사용 맥락은 대화 상대와 상황에 따라 달라질 수 있으므로, 상세 설명과 주의사항을 함께 확인해 주세요.
